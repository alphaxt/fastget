Set up fastget

This extension catches downloads in your browser and hands them to the fastget app, which does the fast multi-connection downloading. The app is free and open source. You install it once.

1. Install the fastget app (Windows)

Download and run the installer. It sets everything up, including the connection to this extension. No command line needed.

Download fastget for Windows

Checking whether the app is installed…

2. That's it

Once the app is installed, start a download as usual. fastget will ask where to save it, then show live progress with pause, resume and cancel. Open the full download list from the toolbar button any time.

Downloads that need a login (optional)

For files behind a login (members-only or paid areas), fastget needs to reuse that site's session. Grant this only if you need it:
