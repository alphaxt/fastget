# fastget Privacy Policy

**Last updated:** 2026

**fastget** is a high-speed download manager consisting of a browser extension and a local desktop application that runs on your personal computer. It is designed from the ground up to ensure that your private data never leaves your machine.

---

### What the Extension Accesses

* **Downloads:** When a download begins, the extension reads the download URL, suggested file name, file size, and the referring webpage URL so the local fastget app can download the file.
* **Website Cookies (Optional):** Only accessed if you explicitly enable the option, allowing downloads from websites that require user authentication or active login sessions. These cookies are sent strictly to your local fastget desktop app for that specific download. Public downloads work without cookies.
* **Local Storage:** Used solely to save your local extension preferences (e.g., number of parallel connections, prompt behavior, download threshold).
* **Tabs:** Used to determine the active tab's URL to provide a valid `Referer` header for downloads that require it.

---

### Where Your Data Goes

* **100% Local Processing:** All intercepted download data is transferred solely to the fastget application running locally on your own computer via native messaging (loopback).
* **No Telemetry or Tracking:** Neither the extension nor the desktop application collects, tracks, or transmits your browsing history, URLs, cookies, personal details, or telemetry to the developer or any third parties.
* **Direct Server Connection:** The desktop application connects directly to the server hosting the target file to download it, exactly as your web browser does.

---

### Data Retention

All downloaded files, history, and configuration settings are stored locally on your device and can be cleared or deleted by you at any time.
